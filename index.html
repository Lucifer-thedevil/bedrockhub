HOW TO INSTALL

Android Installation
  1. Download the .mcworld file.
  2. Open your Downloads folder.
  3. Tap the downloaded file.
  4. Choose Minecraft to import the world.
iPhone / iPad Installation
  1. Download the world file.
  2. Save it to your Files app.
  3. Use the Share option to open it in Minecraft.
Are the downloads safe?
  • Only download files from trusted sources.
  • Our intended world-download format is .mcworld.
  • Never install unknown APK files to access a farm.
  • Back up your Minecraft worlds regularly.
